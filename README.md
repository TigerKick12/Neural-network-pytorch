# Нейронная сеть на PyTorch

Учебный проект по машинному обучению: разработка и обучение полносвязной нейронной сети на синтетических данных.

### О проекте
Модель обучается находить нелинейные зависимости между четырьмя входными признаками и одной целевой переменной.

### Архитектура модели
- Входной слой: 4 признака.
- Скрытый слой: 60 нейронов.
- Функция активации: ReLU.
- Выходной слой: 1 нейрон.

### Обучение
- 1000 синтетических объектов.
- Разделение данных: 70% — обучение, 15% — валидация, 15% — тестирование.
- Оптимизатор: Adam.
- Функция потерь: Mean Squared Error (MSE).
- Количество эпох: 200.
- Размер батча: 32.

### Результат
Модель обучается на тренировочной выборке, а качество обучения контролируется на валидационной. Итоговая оценка проводится на отдельной тестовой выборке.

**Test MSE: 0.0526**

### Используемые технологии
